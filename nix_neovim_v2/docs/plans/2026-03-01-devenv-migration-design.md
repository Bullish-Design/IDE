# Devenv.sh Migration Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the fragile `flake.nix` devShell with a clean `devenv.sh` environment using `wrapNeovimUnstable` + `makeNeovimConfig` for proper plugin loading, and fix the broken treesitter config.

**Architecture:** Use devenv.sh (`devenv.nix` + `devenv.yaml`) to create a development environment. Build a properly wrapped Neovim binary via `pkgs.wrapNeovimUnstable` that has all plugins (including mini.nvim from source and treesitter with grammars) in its native packpath. Provide an `nv2` startup script via devenv's `scripts` module. Fix `treesitter.lua` to use the modern nvim-treesitter 0.10+ API.

**Tech Stack:** Nix, devenv.sh, Neovim 0.11, nvim-treesitter 0.10, Lua

### Task 1: Create devenv.yaml

**Files:**
- Create: `devenv.yaml`

**Step 1: Write devenv.yaml**

```yaml
inputs:
  nixpkgs:
    url: github:NixOS/nixpkgs/nixos-unstable
```

This tells devenv.sh to use nixos-unstable as its nixpkgs source, matching what flake.nix uses.

### Task 2: Create devenv.nix

**Files:**
- Create: `devenv.nix`
- Reference: `plugins.nix` (no changes)

**Step 1: Write devenv.nix**

The devenv.nix must:
1. Build mini.nvim from source (same as flake.nix)
2. Import all plugins from `plugins.nix`
3. Bundle nvim-treesitter with specific grammar parsers (replaces `ensure_installed`/`auto_install`)
4. Use `wrapNeovimUnstable` + `makeNeovimConfig` to create a Neovim with plugins in packpath
5. Include all LSP servers, formatters, linters, and tools (matching hm-module.nix)
6. Define an `nv2` script that launches the wrapped neovim with `-u $DEVENV_ROOT/nvim/init.lua`

Key details:
- `nvim-treesitter.withPlugins` bundles parsers into the plugin derivation
- `makeNeovimConfig { plugins = [...]; }` generates proper packpath config
- `wrapNeovimUnstable` creates a wrapped binary with everything baked in
- The `nv2` script uses `$DEVENV_ROOT` (set by devenv.sh) for the config path
- Since plugins are in packpath, Lua's `require()` automatically finds them -- no manual `package.path` wiring

### Task 3: Fix treesitter.lua for nvim-treesitter 0.10+ API

**Files:**
- Modify: `nvim/lua/plugins/treesitter.lua`

**Step 1: Rewrite treesitter.lua**

The old `require("nvim-treesitter.configs").setup({...})` API no longer exists in nvim-treesitter 0.10+. The module is now `nvim-treesitter.config` (singular) and only handles parser install directory config.

In a Nix-managed environment:
- Parsers are provided by `nvim-treesitter.withPlugins` (no `ensure_installed` needed)
- Highlighting uses Neovim's built-in `vim.treesitter.start()` 
- Indentation uses Neovim's built-in treesitter indent
- Incremental selection needs to be done via keymaps using `vim.treesitter` API

The rewritten treesitter.lua should:
1. Enable treesitter highlight via autocmd calling `vim.treesitter.start()`
2. Enable treesitter-based indentation via `vim.bo.indentexpr`
3. Set up incremental selection keymaps manually
4. Configure treesitter-context (this plugin's API is unchanged)
